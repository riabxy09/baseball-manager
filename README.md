# Baseball Manager - GitHub 기반 기본 프로젝트

## 파일
- `index.html` : 화면의 기본 뼈대. 로고/게임명/인트로 이미지를 쉽게 수정할 수 있습니다.
- `game.js` : 선수, 오버롤, 등급, 강화, 뽑기, 리그, 홈런더비, 친선경기 UI 및 서버 통신 구조.
- `style.css` : 기본 디자인.

## 인트로 이미지
프로젝트 루트에 `intro.png`를 넣으면 인트로 화면에서 자동으로 표시됩니다.

## GitHub Pages
이 프로젝트는 그대로 GitHub Pages에 올려 프론트엔드를 실행할 수 있습니다.

단, GitHub Pages는 정적 호스팅이므로 실제 2인 실시간 경기는 별도의 서버가 필요합니다.
`game.js`의 `SERVER_CONFIG.websocketUrl`에 WebSocket 서버 주소를 넣는 방식으로 연결하도록 설계했습니다.

## 다음 단계
실제 서비스용으로 발전시키려면:
1. 사용자 계정/인증
2. 서버 DB
3. 선수 영구 저장
4. 강화 성공/실패를 서버에서 판정
5. 뽑기 결과를 서버에서 판정
6. 방 생성/참가 및 실시간 경기 상태 동기화
7. 치팅 방지
8. 리그 시즌/랭킹 저장
9. 선수 카드/스킨/구장 등 콘텐츠 확장

특히 코인, 강화, 뽑기 등은 클라이언트에서만 처리하면 조작이 가능하므로 실제 배포에서는 반드시 서버에서 처리해야 합니다.
